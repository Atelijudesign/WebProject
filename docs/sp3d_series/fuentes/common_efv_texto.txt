===== PAGINA 2 =====
 
 
 
LAB-1: Archivos de sesión, Tasks, Vistas y Ventanas. 
 
Objetivo: 
Después de este ejercicio serán capaces de crear un archivo de sesión, modificar la configuración, 
orientación de vistas y moverse dentro del modelo. 
 
1. Iniciar SP3D, para esto debemos ir a Inicio-Programs-Intergraph SmartPlant 3D-SmartPlant 
3D. 
2. En el cuadro de dialogo New seleccione en archivo Emply y haga click en Ok. 
 
3. En el menú de Tasks seleccione Configure Tasks List para configurar las disciplinas o 
módulos que se desean agregar a las opciones de selección. 
 
 
 
 


===== PAGINA 3 =====
 
 
4. Seleccione todos los Tasks ubicados al costado izquierdo y haga click en Add, luego haga 
click en Ok. 
5. Ahora seleccione el Tasks Common del menú de Tasks. 
6. En el desplegable de Windows seleccione New Windows hasta completar 4 ventanas 
abiertas. 
7. En el menú desplegable de Windows selecciona Tile Horizontally. 
8. Active el Graphic Views 1 haciendo click en la barra. 
9. Desde la opción de Named Views ubicada en la barra del Common seleccione la opción 
Front para tener una vista de frente. 
 
 
10. Del mismo modo haremos con las demás vistas colocando orientación Top, Right y vista 
Isometric para completar las cuatro ventanas con vistas distintas. 
11. Selecciones Tools en la barra desplegable superior y seleccione Option el cual abrirá un 
cuadro de dialogo. 
12. En la pestaña de Units of Measure seleccione ft-in para distancia. 
 


===== PAGINA 4 =====
 
 
13. Seleccione de la pestaña File la opción Save as y guarde la sesión en su escritorio, esto le 
dará un acceso directo a la sesión que usted ha creado. 
14. Ahora seleccione de la pestaña File la opción Define Workspace para crear su espacio de 
trabajo. 
15. Seleccione la planta o proyecto de entrenamiento disponible. 
16. Seleccione la casilla de Filter para seleccionar el filtro deseado y haga click en More. 
17. Expanda la carpeta Plant Filters y seleccione el filtro All y haga click en Ok.

LAB-2A: Filter Management-Object type. 
Después de este ejercicio serán capaces de seleccionar objetos 
usando filtros Object Type.

dialogo. 
2. Expanda la carpeta Default Filters, SP3D Object Filters, Object Type y seleccione el filtro 
de Structure. 
3. Haga click en Ok para seleccionar toda la estructura contenida en el filtro. 
4. La vista debe ser igual a la siguiente imagen. 


===== PAGINA 11 =====
 
 
 
 
5. En Tools ubicado en la barra superior seleccione Hide. 
6. Ahora su vista debe ser igual a la siguiente imagen. 
 
7. En Tools seleccione Show All. 
8. En Tools seleccione Select By Filters y se abrirá el cuadro de dialogo. 
9. Expanda la carpeta Default Filters, SP3D Object Filters, Object Types y seleccione el filtro

selecciona Style by Rule como opción de color.

LAB-2C: Filter Management-Volumen Filters. 
Después de este ejercicio serán capaces de crear filtros de 
visualización basados en volúmenes. 
 
1. Seleccione Define Workspace y seleccione More. 
2. Seleccione la carpeta My Filters. 
3. Seleccione el icono de Simple Filter, se abrirá el cuadro de dialogo.

la tecla de CTRL presionada y de la pestaña de Volume seleccione igual el Volume 
U01. 
7. Haga click en Ok. 
8. Ahora seleccione el filtro que acaba de crear y haga click en Ok. 
9. La vista debe ser similar a la siguiente imagen. 


===== PAGINA 13 =====

LAB-3: Inserting Control Points 
Después de este ejercicio serán capaces de colocar puntos de 
control en los objetos deseados. 
 
1. Seleccione el filtro U01 desde el Workspace. 
2. En la barra superior seleccione Format>View, esto abrirá un cuadro de dialogo. 
3. Seleccione Reference Geometry de la lista de Aspects. 
4. Haga click en aceptar para cerrar el cuadro de dialogo. 
5. En la barra superior seleccione Insert y seleccione Control Point. 
6. Seleccione el Equipo E-102 para relacionar el Control Point. 
 


===== PAGINA 14 =====
 
 
 
7. En la casilla de Sub-Type seleccione Process Equipment. 
8. Coloque el Control Point en el nozzle N1. 
 
9. Seleccione el Control Point y revise el cuadro de propiedades y modifíquela según 
lo desee.
